# Epigram
[Epigram] 은 글 작성과 공유를 중심으로 한 커뮤니티 웹 애플리케이션입니다. 사용자는 글 작성 시 저자, 출처, 태그 등의 정보를 함께 입력할 수 있으며, 작성된 글은 실시간으로 목록에 반영됩니다. 댓글, 좋아요, 수정/삭제 등 기본적인 커뮤니티 기능과 함께 무한 스크롤 기반의 글 탐색, OAuth 간편 로그인, 활동 내역 시각화 기능 등을 제공합니다. 이를 통해 사용자 친화적인 커뮤니티 경험을 구현하는 것을 목표로 합니다.
